## What MobsManager Does

MobsManager lets you decide which mobs may spawn, where they may spawn, and under which spawn categories they remain allowed.

It is built for administrators who want reliable world-by-world control without maintaining a heavy or obscure configuration system.

## Highlights

- Per-world mob spawn management
- Fine-grained control by spawn category
- Compatibility with legacy entity names from older plugin versions
- Java 17 and Spigot API 1.21.1 support
- Versioned documentation powered by Material for MkDocs and mike
